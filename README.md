## Software and Websites
cant make a game without assets, especially if made by yourself.

### 2D
starting on Unity, i use some softwares/websites to make 2D assets, most of them are pixels/8-bit.

- PixiEditor (Swiss Army Knife. can do Pixel, Brush, and Vector all in one place)
- Inkscape (Vector graphics)
- Photoshop (License has expired, so i cant use it now)
- Affinity (by far the best Photoshop alternative i could find for free)
- Photopea (web alternative to Photoshop)

### 3D
starting on Godot, i decide to dive deeper into 3D.

- Roblox Studio (specifically its Union mesh features, though its making quite a mess and is inaccurate. moved on to Blender)
- Blender (got a good grip on the basic workflow right now)

### Audio
with games comes with audio. here is a list of software/websites that i use to make music and sound effects.

- BeepBox (including mods)
  - JummBox
  - UltraBox
- Bfxr (and also jsfxr, both achieve a similar goal)

- LMMS (Linux Multi Media Studio)
